## Phase Goal

Verbatim from `.planning/ROADMAP.md` §Phase 4. Not in `As a … I want to … so that …` form and not
rewritten here — run `/gsd mvp-phase 4` if the three-slot form is wanted.

> Groups run the ban ritual their own way on one shared screen, and nobody sees what they should
> not have seen

**Slice delivered by this plan:** the rules of the ritual become executable and testable before any
pixel exists — a group's ban order, whose turn it is, what the room is allowed to see at each moment,
and who collided with whom. Every one of those is a rule, and `04-UI-SPEC` §Pure-core boundary
forbids a component from owning one.

<objective>
Derive everything about the ban stage that is derivable, in `src/core/selectors.ts`, beside
`selectCardTurn` and `selectStartingOrder`.

Purpose: two of these are secrecy controls rather than conveniences. `selectPublicBanIds` is the
single answer to "what may the room see right now", and it is what closes the top bar's `Bans (N)`
disclosure — the least obvious leak channel in the phase, a native `<summary>` anyone can open with
one click. `selectBanStageState` is the one place the screen mode is decided, so "the entry surface
is showing while the reveal has landed" is unrepresentable.

Output: seven selectors, and the serpentine derivation the codebase has never had.
</objective>

```ts
// src/core/selectors.ts
export interface BanTurn { playerId: string; pass: number; index: number; }
export interface BanCollision { monId: string; playerIds: string[]; }

/** D-12. A free function over primitives, matching `selectStartingOrder`. */
export function selectBanOrder(order: readonly string[], bansPerPlayer: number): string[];

/** Whose turn, which pass, and how far into the sequence. `null` when the stage is done. */
export function selectBanTurn(state: DraftState): BanTurn | null;

/** The ONE place the ban stage's screen mode is decided — components branch, never compute. */
export type BanStageState = 'snake' | 'blindLocked' | 'blindEntry' | 'reveal' | 'notRunning';
export function selectBanStageState(state: DraftState): BanStageState;

/** What the room may see right now — Amendment 1's four-row table. */
export function selectPublicBanIds(state: DraftState): string[];

/** Host bans ∪ every revealed or placed player ban, deduped. The reveal's re-check input. */
export function selectAllBanIds(state: DraftState): string[];

export function selectSubmittedPlayerIds(state: DraftState): string[];
export function selectBanCollisions(state: DraftState): BanCollision[];
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| the fold → what is rendered | This is the phase's principal trust boundary and it is entirely inside `src/core/`. Submitted bans are plaintext in the log (D-06); the only thing standing between them and the shared screen is which ids a selector hands to a component. |
| `selectPublicBanIds` → `TopBar`'s `<summary>` disclosure | A native `<details>` any person in the room can open with one click. Whatever this selector returns is one click from readable by everyone present. |
| `selectAllBanIds` → a displayed count | A caller that takes `.length` from this instead of asking `bannedEntries` reports a number that is wrong by exactly the number of collisions. |
