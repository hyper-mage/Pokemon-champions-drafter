## Phase Goal

Verbatim from `.planning/ROADMAP.md` §Phase 4. Not in `As a … I want to … so that …` form and not
rewritten here — run `/gsd mvp-phase 4` if the three-slot form is wanted.

> Groups run the ban ritual their own way on one shared screen, and nobody sees what they should
> not have seen

**Slice delivered by this plan:** a snake player looking at the shared screen can see, at a glance,
which Pokémon are already gone and who spent them — and cannot waste their turn clicking one. Before
this plan the click was refused by a backstop with no explanation on screen.

<objective>
Teach the two ban surfaces to render an option inert with a stated reason, and wire the snake pool
pane to the one selector that decides which.

Purpose: this is the phase's governing interaction pattern, and `selectCardOffer`'s doc block at
`selectors.ts:477-483` states it — the constraint belongs upstream of the click, not in a rejection
after it. `canApply`'s `banAlreadyPlaced` arm exists behind this as a backstop; if it ever fires for
a real host, the surface and the rule have disagreed and that is a bug.

Output: one new `PoolGrid` prop, one new `TypeaheadField` prop, and the snake pool pane wired to
`selectPublicBanIds`.
</objective>

```ts
// src/ui/components/PoolGrid.tsx
/**
 * Why a species may not be banned again, or `null` when every cell is live.
 *
 * ONE prop carrying the whole answer, for `roundRestriction`'s reason: a caller that could
 * supply the ids without the copy would be a caller that could render `undefined — banned by`.
 */
export interface BanInertState {
  /** Ids that may not be banned again. */
  ids: ReadonlySet<string>;
  /** The suffix for a cell's accessible name, keyed by id. Every id in `ids` has one. */
  reasonFor: (monId: string) => string;
  /** The one visible rule line above the grid. */
  ruleLine: string;
}
banInert?: BanInertState | null;   // defaults to null, applied once inside the component

// src/ui/components/TypeaheadField.tsx
/** Per-option inert state. Defaulted to `() => null` once inside the component. */
optionState?: (entry: T) => { inert: true; reason: string } | null;
```
