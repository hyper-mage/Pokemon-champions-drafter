## Phase Goal

Verbatim from `.planning/ROADMAP.md` §Phase 4. Not in `As a … I want to … so that …` form and not
rewritten here — run `/gsd mvp-phase 4` if the three-slot form is wanted.

> Groups run the ban ritual their own way on one shared screen, and nobody sees what they should
> not have seen

**Slice delivered by this plan:** the room can look at the shared screen and read the whole ban round
so far — Sam took Garchomp in pass 1, Ada took Landorus, and it is Kim's turn next. Before this plan
previous bans were visible only as struck-through cells with no attribution.

<objective>
Build the player × pass board, in both arms, and hang the public one in the snake board pane.

Purpose: the blind arm is built here rather than in 04-09 on purpose. `04-UI-SPEC` assertion S2
requires that a `BanBoard` rendering blind progress receive **no species ids at all**, and the only
way to make that a type error instead of a review item is for both arms to be members of one
discriminated union declared in one place. A component that never receives a name cannot render one.

Output: `BanBoard` with two arms, its stylesheet, and the snake board pane.
</objective>

Write `BanBoard` as a **discriminated union on `mode`**, exactly the shape `<interfaces>` gives. The
props are the leak defence: `04-UI-SPEC` assertion S2 requires the blind arm to receive no species
ids, and a component that never receives a name cannot render one. Put that sentence in the
component's doc block, because a later contributor "simplifying" the two arms into one props type
with optional fields would silently remove the guarantee.

Copy `BoardGrid`'s geometry rather than inventing one. `grid-template-columns:
var(--board-label-w) repeat({passes}, minmax(0, 1fr))` with `gap: var(--space-2)`, and the row label
ellipsised on one line by `BoardGrid`'s shipped mechanism. **`--board-label-w` is referenced, never
re-declared** — a second literal 176px is a second thing that can drift from the draft board beside
it.

`Pass`, never `Round`. `Round` is taken by the draft's own rounds and by the board's `R{n}` header,
and two meanings for one word on a shared screen is how a room ends up arguing about which round it
is (`04-UI-SPEC` §6).

Mark the next cell with `board__cell--next` — accent border plus `--color-accent-soft` tint, which
is accent reserved use 1 and a shipped mechanism on a new grid. The component **renders** the answer;
`selectBanTurn` decides it and 04-06's wiring passes it in.

Ban-board cells are **not interactive**. `03-UI-SPEC` Amendment 1 made a board cell interactive
under four conditions, all four of which are about swaps, and none holds here. No `tabindex`, no
click handler, no roving tabindex on either arm — the progress board is at most 8 static rows and
neither is a large uniform interactive set, which is what `use-roving-tabindex` exists for. State
that in a comment so the hook is not wired out of habit.

Emit `<div>`s in a CSS grid, matching `BoardGrid` exactly, with **no** `role="grid"`, `role="row"`
or `role="gridcell"` — the shipped board does not invent them and a second, differently-shaped board
would be a second accessibility model for one visual pattern.

Styling is plain CSS from `src/ui/tokens.css`: `--text-label` for the column headers, `--text-heading`
for the row labels, `--text-body` for `Entered` / `Not yet`, `--space-2` for the gap. Each `--text-*`
token is a complete `font` shorthand (`tokens.css:34-36`); a rule that sets `font-size` alone is
off-contract.

Write `tests/ui/ban-board.test.tsx` (`// @vitest-environment happy-dom` first line, `announce('')` in

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `BanBoard`'s props → the shared screen | The blind arm renders while the secret half of the ritual is running. Anything it can receive, the room can read. |
| selector output → board rows | The rows are a fold of the log. A component that kept its own board state would be a second copy of a fact the log already asserts, free to drift after an undo. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-04-35 | Information disclosure | `BanBoard` `mode="blind"` | mitigate | The discriminated union gives that arm `{ playerName, entered }` and nothing else, so a species name has no route into it.
