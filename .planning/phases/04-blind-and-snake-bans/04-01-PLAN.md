> not have seen

and the blind slice, and no mode-specific work is in it. It delivers nothing a player sees. Every
plan after this one is a vertical slice.

bounds, six updated shipped assertions and one new resume test.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| imported / hand-edited JSON file → `import-guard.ts` | The only untrusted input this project has. A crafted file can claim any value for either new field. |
| `localStorage` wrapper record → `persistence.ts` → `migrate` | A record written by an older build, or one edited in devtools. `JSON.parse` runs here **without** a reviver, which is why `safeObject` / `hasPoisonKey` exist on this path. |
| host-typed `bansPerPlayer` → the saved document | A number the host typed becomes a number a later build re-reads. If the guard's bound is lower than the gate's, this build creates files it refuses to open. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Denial of Service | `bansPerPlayer` → `players × bansPerPlayer` → `drawPool` | mitigate | Bounded at `MAX_BANS_PER_PLAYER = 24` in `buildConfig`, the same constant 04-02's gate reads. `draw.ts:108-112` documents a deliberate uncaught `RangeError` on an oversized `count`; this bound plus 04-02's pessimistic gate are what keep it unreachable. |
| T-04-02 | Tampering | `duplicateBanPolicy` | mitigate | Rebuilt against the `DUPLICATE_BAN_POLICIES` union; an unrecognised value coerces to `'bothApply'` rather than being carried. A stored value outside the union would become live the moment a later milestone starts reading it. |
| T-04-03 | Tampering | two copies of the v3 default table | mitigate | `buildConfig` imports `V3_CONFIG_DEFAULTS` from `migrate.ts`. Two tables can disagree about what a Phase 3 tournament was — `migrate.ts:78-81`. Asserted by a grep for an inline default literal returning 0. |
| T-04-04 | Denial of Service | a schema-3 save that stops resuming | mitigate | `SUPPORTED_SCHEMA_VERSIONS` is asked rather than `SCHEMA_VERSION` compared, so the wrapper site moves by definition. The residual risk is the missing **test**, closed by `describe('a draft saved by Phase 3')`. |
