  <action>
    Write `scripts/check-pure-core.mjs`, a zero-dependency Node script that fails the build
    when anything under `src/core/` reaches for ambient state. SHEL-04 requires this be
    enforced by a check, not by inspection.

    Implementation requirements:

    - Accept an optional directory argument, defaulting to `src/core`. This lets the
      script be pointed at the fixture directory for its own self-test.
    - Recursively collect `.ts` and `.tsx` files. If the directory contains no such files,
      exit 0 (the core is empty in this plan; it fills up in plan 06).
    - BEFORE matching, strip line comments, block comments, and string/template literals
      from the source text. A naive `grep -c` counts its own documentation and produces
      self-invalidating gates; this script must not have that flaw. Replace stripped
      regions with equal-length whitespace so reported line numbers stay accurate.
    - Forbidden identifiers, matched on the stripped text as whole words:
      `Date.now`, `new Date`, `Math.random`, `localStorage`, `sessionStorage`,
      `indexedDB`, `fetch`, `XMLHttpRequest`, `document`, `window`, `navigator`,
      `crypto`, `performance`, `BroadcastChannel`, `setTimeout`, `setInterval`,
      `requestAnimationFrame`, `process`, `dangerouslySetInnerHTML`, `innerHTML`.
    - Forbidden import specifiers: any `from` clause whose target contains `adapters`
      or `/ui` or `ui/`, and any bare specifier that is not `preact`-free — specifically,
      importing `preact` or `@preact/signals` from `src/core/` is forbidden too, because
      the core must be renderer-agnostic.
    - On any hit, print `path:line:col  forbidden: <token>` for every occurrence and exit 1.
      On no hits, print the file count checked and exit 0.

    Then create two fixture files so the checker is itself tested rather than trusted:
    - `scripts/__fixtures__/pure-core-sample.ts` — a pure function plus a comment and a
      string literal that both contain the words `Date.now` and `localStorage`. Running
      the checker against `scripts/__fixtures__` must NOT flag these, proving the
      comment/string stripping works.
    - `scripts/__fixtures__/impure-core-sample.ts` — a function that actually calls
      `Date.now()` and reads `localStorage`. This must be flagged.

    Because both fixtures live in one directory, write the self-test as two invocations
    against two subdirectories: put the pure sample under `scripts/__fixtures__/pure/`
    and the impure one under `scripts/__fixtures__/impure/`.

    Wire `npm run check:pure` to run the script against `src/core`, and add
    `npm run check:pure:selftest` running both fixture directories and asserting the
    expected exit codes.

    Exclude `scripts/__fixtures__` from tsconfig `include` so the impure sample does not
    fail typecheck.
  </action>
  <acceptance_criteria>
    - `node scripts/check-pure-core.mjs src/core` exits 0

    - `node scripts/check-pure-core.mjs scripts/__fixtures__/pure` exits 0, proving comments and string literals are stripped before matching
    - `package.json` scripts contains a `check:pure` entry invoking `scripts/check-pure-core.mjs`
