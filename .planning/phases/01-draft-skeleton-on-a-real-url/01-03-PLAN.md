    `src/core/roster/transform.ts` exports three pure functions:

      classify(species, byId)  — returns a tagged result as specified in the behavior block.
        Rules, in priority order:
          1. truthy `isNonstandard` (ANY value, including "Future") → excluded/nonstandard.
             The correct filter is absence of the field, NOT `!== 'Past'`.
          2. `tier === 'Illegal'` → excluded/illegalTier
          3. `forme` starts with 'Mega' AND `requiredItem` is set → megaForme
          4. truthy `battleOnly` → excluded/battleOnly. (Rule 3 runs first so Megas,
             which are also battleOnly, are already claimed.)
          5. `baseSpecies` differs from `name` AND the entry's `types` array and
             `baseStats` object both deep-equal the base species entry's → excluded/cosmetic
          6. otherwise → draftable

      deriveMegaFormes(baseSpeciesId, byId) — collects every legal species whose
        `baseSpecies` resolves to the same id, whose `forme` starts with 'Mega', and which
        has a `requiredItem`. Returns them sorted by id. NEVER use `id.includes('mega')`:
        that returns 77 matches of which `meganium` is not a Mega. NEVER use
        `name.split('-')`: `Kommo-o` becomes base "Kommo" forme "o".

      transform(rawSpeciesList, meta) — runs classify over everything, folds the megaFormes
        onto their base species as the `megaCapable` flag plus the `megaFormes` array
        (ROST-07, ROST-08: the draftable unit is the base species; Mega is a flag, not a
        pool row), computes the `counts` object, sorts `entries` by `id` for deterministic
        output, and returns the snapshot without `checksum` (the script adds that).

    Identity discipline (PITFALLS Pitfall 4, "two fields never one"): `id` is used for all
    equality, keying, storage, and set membership. `name` is used only for rendering and
    export. Never compare display names. Never derive structure from a name string.

    Keep `transform.ts` free of every token in the purity gate's forbidden list — no
    `Date.now()`, no `fetch`, no `process`. The caller supplies `generatedAt` in `meta`.
