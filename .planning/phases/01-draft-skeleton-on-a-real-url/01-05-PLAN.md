<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| committed snapshot JSON → DOM | Roster display names, including U+2019 and other non-ASCII, are rendered as text |
| network fetch of own-origin assets → app state | The only fetch in the app; same-origin, static, no credentials |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-04 | Information Disclosure | rendering roster strings into the DOM | mitigate | Preact escapes text children; `npm run check:nohtml` fails the build on any `innerHTML` or `dangerouslySetInnerHTML` anywhere under `src/`, and it runs in the workflow's verify job |
| T-01-25 | Tampering | snapshot fetched over the network at runtime | mitigate | Same-origin static asset served from the project's own Pages deployment over HTTPS; no third-party origin is contacted at runtime; the failure path shows the specified copy rather than half-loading |
| T-01-26 | Denial of Service | rendering roughly 230 image cells at once | accept | Explicitly measured as unremarkable in CLAUDE.md; virtualization libraries are forbidden. `content-visibility: auto` is the one sanctioned hatch if profiling ever demands it |
| T-01-27 | Spoofing | sprite `src` constructed from data | mitigate | The path is built from the numeric `spriteId` only, interpolated into a fixed same-origin template prefixed with `import.meta.env.BASE_URL`. No roster-supplied string reaches a URL |
</threat_model>
