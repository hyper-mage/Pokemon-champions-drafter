<objective>
Give the app a way to know a snapshot has expired without asking anyone, and give the service worker
the one instruction that makes an explicit refresh reach the network.

Purpose: M-B's `validUntil` is `2026-09-02`. This banner fires on the committed snapshot within days
of shipping with nobody doing anything, so it is an acceptance path rather than a hypothetical. And
`cache: 'reload'` does **not** bypass a service worker — the worker still intercepts, and
`ignoreSearch: true` makes a cache-busting query string invisible to the cache lookup. Both facts
together mean a naive same-origin refresh is a no-op that works perfectly in `npm run dev`.

Output: one pure predicate, one clock read, one early return, and the two tests that pin them.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| the service worker → every same-origin `GET` | The worker decides whether a request sees the network at all. A widened bypass is a widened attack surface on every asset the app ships. |
| the wall clock → `src/core/` | `check:pure` forbids the crossing. The date is stamped at the edge and handed in as a string. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-05 | Tampering | the `?refresh` early return as a general precache-bypass primitive | mitigate | The return sits **third**, after the non-GET and cross-origin guards, so it can only widen behaviour for same-origin `GET`s that already reach the worker. It bypasses only the cache lookup — it fetches nothing itself, interpolates nothing, and issues no request. A malicious page cannot reach it: it is same-origin by the guard above it. Ordering is pinned by two `grep -n` acceptance criteria, not by review. |
| T-05-06 | Denial of service | a stale worker serving old bytes indefinitely | mitigate | The cache name hashes file **content** (`build-sw-manifest.mjs`), so changing `sw.js` changes the cache name automatically and no manual invalidation exists to get wrong. The two lifecycle overrides stay absent and are pinned by `grep -c … returns 0`. |
| T-05-07 | Information disclosure | `credentials` on a refresh request | mitigate | Not introduced here — this plan issues no `fetch`. 05-04 owns the request and carries `credentials: 'omit'` on `fetchJson`'s existing shape. Recorded so the boundary is not assumed to be covered by this plan. |
| T-05-08 | Tampering | a timezone-dependent staleness verdict | mitigate | `todayIso()` reads local date parts and the comparison is lexicographic over zero-padded ISO strings. No `Date` is constructed inside `src/core`, and `check:pure` fails the build if one ever is. Two boundary tests pin the half-open interval against the shipped manifest's own M-A/M-B handover date. |
| T-05-SC | Tampering | npm/pip/cargo installs | accept | This plan installs nothing. `package.json` is not modified; `05-RESEARCH.md` §Package Legitimacy Audit records zero packages for the phase. |
