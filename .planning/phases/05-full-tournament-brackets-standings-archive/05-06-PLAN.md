rewritten here — run `/gsd mvp-phase 5` if the three-slot form is wanted.

> The night runs past the draft — round robin, a seeded cut, a single-elimination bracket, results
> recorded and correctable — and the finished tournament stays readable and re-runnable after the
> Champions roster rotates

**Slice delivered by this plan:** the bracket becomes a fact about the cut and the results, and a
correction becomes something the tool can describe before it happens. Both are pure, both are
testable at 5, 6 and 7 players with no DOM, and neither can be got right afterwards by a component.

**One ruling this plan makes, flagged by RESEARCH as not covered by the UI-SPEC at all:** the cut
must be inert when it would split an unresolved tie block, and the contract supplies no copy for it.
The sentence is:

> `The cut at {n} splits a tie. Order the tied players yourself before you take it.`

It follows the shape of the contract's own blocked reason (`{k} matches are still to play. Record
them all before you cut.`) — states the problem, names the next action, second person, present
tense. The rule lives here; the sentence is rendered by 05-11.

**D-10's literal two-action shape is followed, not optimised.** RESEARCH records that a single
`matchRecorded { voids: [...] }` would be atomic by construction and would satisfy every stated
purpose of D-10. D-10 is locked and says "an explicit clearing action", which is specific enough that
reading it as a field would be an override rather than an interpretation. Both dispatches are
synchronous in one handler and autosave is a 300ms trailing debounce, so no partial correction can
reach storage. This plan supplies the selector both actions are driven by; 05-08 supplies the two
actions.
</precedence>

```ts
// src/core/tournament.ts
export interface BracketMatch {
  matchId: string;              // `br:{round}:{slot}`, both 1-based
  upperId: string | null;       // null = not known yet, or a phantom (bye)
  lowerId: string | null;
  isBye: boolean;
  /** `Final` | `Semi-final` | `Quarter-final` | `Round of {n}` — by matches-in-round. */
  roundLabel: string;
}
export interface Bracket {
  rounds: readonly (readonly BracketMatch[])[];
  final: BracketMatch;
  /** Non-null only once the final is recorded. */
  championId: string | null;
}
export function selectBracket(state: DraftState): Bracket | null;

/** D-17. A final recorded with no later reopen. */
export function selectTournamentLocked(state: DraftState): boolean;

/** The `{b}` in `Top {n} advance. Seeds 1 to {b} get a bye.` `0` when n is a power of two. */
export function byeCountForCut(n: number): number;

/** Pitfall 4. True when seeds n and n+1 are members of one unresolved block. */
export function selectCutSplitsTiedBlock(state: DraftState, n: number): boolean;

export interface VoidCascade {
  /** Log seqs to void. Empty means nothing downstream is affected. */
  targetSeqs: readonly number[];
  /** How many MATCH results are in `targetSeqs` — the `{n}` the button interpolates. */
  matchCount: number;
  /** True when the cut itself is voided — the `Record and void the bracket` label. */
  voidsCut: boolean;
}
export function selectVoidCascade(
  state: DraftState,
  matchId: string,
  nextWinnerId: string,
): VoidCascade;
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `state.cut.seeds` → the bracket a room plays | An imported document's `seeds` array is untrusted content driving what the screen says the pairings are. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-25 | Tampering | a forged locked/unlocked state on an imported document | mitigate | Locked is a fold of a final result against `lastReopenSeq`, not a stored flag, so a document cannot claim to be unlocked when it is not. | T-05-26 | Repudiation | a bracket seeded from an unresolved tie | mitigate | `selectCutSplitsTiedBlock` refuses the cut upstream of the click with its own stated reason, and 05-08's `canApply` refuses it as `cutSplitsTiedBlock`.
