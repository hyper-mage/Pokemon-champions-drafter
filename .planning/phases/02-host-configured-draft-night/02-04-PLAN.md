## Phase Goal

Verbatim from `.planning/ROADMAP.md` §Phase 2. **Note: this Goal line is not written in
`As a … I want to … so that …` form**, and was not rewritten here — see 02-01-PLAN.md.

> A host sets up a real tournament for their group — names, format, pool size, banlist —
> and 4–8 friends draft through it on one shared screen with everything they need visible
> at once.

**Slice delivered by this plan:** a host opens the app, clicks New tournament, types six
friends' names, picks a format label and a depth, sees the randomized starting order numbered
on screen, and clicks Start draft — and a real six-player draft begins on the existing board.
End to end: landing → config form → `checkFeasibility` → `drawPool` → `createTournament` →
`dispatch` → `fold` → the draft screen.

<objective>
Replace `app.tsx`'s auto-create-on-load with a landing screen and a real config screen, and
change `createTournament` from a constant-reader into a seam that takes a host-authored config.

Purpose: this is the plan where the two hardcoded Phase 1 players stop existing. It is also
where RULE-07 becomes visible — a disabled Start that states its reason, reachable by keyboard,
recomputed on every keystroke.

Output: `LandingScreen`, `ConfigScreen` with its Players and Tournament groups, `PlayerList`,
`FeasibilityBar`, and a `createTournament` that invents nothing.
</objective>
