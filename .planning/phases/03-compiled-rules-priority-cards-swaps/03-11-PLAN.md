## Phase Goal

Verbatim from `.planning/ROADMAP.md` §Phase 3 — this Goal line is not in `As a … I want to … so
that …` form and was not rewritten here; run `/gsd mvp-phase 3` if the three-slot form is wanted.

> The draft becomes the one the spec describes — composition requirements compile into a round
> schedule that types the team slots, players bid priority cards for turn order over that visible
> schedule, and swaps can only take something the target slot allows.

**Slice delivered by this plan:** the last pick lands, the screen says `Swap round 1 of 2 — Cy swaps
or passes` with `Swap order reverses round 6.` beneath it, everyone takes their turn or passes, and
only then do the export panels open.

<objective>
Run the dedicated swap rounds, let a player pass, and split completion into the two states the
export gate needs.

Purpose: SWAP-04 exists because every priority card is spent by the last pick, so the swap rounds
need an order with a stated source. D-31 exists because a per-player export panel that opens while
the teams can still change invites somebody to paste a team that is about to be wrong.

Output: `swap/passed`, three selectors, `SwapPanel`, the swap-round routing, and the export gate
moved to the second completion state.
</objective>

```ts
// src/core/actions.ts
export const SWAP_PASSED = 'swap/passed';

export interface SwapPassedPayload {
  type: typeof SWAP_PASSED;
  playerId: string;
  /** 1-based. A pass belongs to a dedicated round; there is no mid-draft pass. */
  swapRound: number;
}

// src/core/selectors.ts
/** Reverse of the last pick round's resolved order — D-28, SWAP-04. */
export function selectSwapRoundOrder(state: DraftState): string[];

/** Which player is on the clock in a given swap round, or null when it is finished. */
export function selectSwapRoundPosition(
  state: DraftState,
  swapRound: number,
): { playerId: string; index: number } | null;

/** Picks complete AND every swap round has `players` recorded moves — D-31. */
export function selectIsTournamentComplete(state: DraftState): boolean;

/** Which source the swap order came from, so SWAP-04's requirement to be explicit is met. */
export function selectSwapOrderSource(state: DraftState): 'lastRound' | 'startingOrder';
```
