## Phase Goal

Verbatim from `.planning/ROADMAP.md` §Phase 3 — this Goal line is not in `As a … I want to … so
that …` form and was not rewritten here; run `/gsd mvp-phase 3` if the three-slot form is wanted.

> The draft becomes the one the spec describes — composition requirements compile into a round
> schedule that types the team slots, players bid priority cards for turn order over that visible
> schedule, and swaps can only take something the target slot allows.

**Slice delivered by this plan:** every board row shows the six priority cards that player still
holds, struck through as they are spent — and the log can record a card being played and a round's
order being resolved. 03-08 puts the control on screen that plays them.

<objective>
Give the log a vocabulary for priority cards, and give the room a place to read every hand at once.

Purpose: D-19 puts one action per card into the log so the shared screen renders from the log rather
than from component state — a refresh mid-bidding loses nothing. D-22's tiebreak is proved here
rather than asserted: `seq` is unique log-wide, so `(value, seq)` is a total order and there is no
third comparator for player-entry order to leak into.

Output: `cards/played` and `order/resolved` in all five places each, two new `DraftState` arrays,
four selectors, `resolvePickOrder`, and the board-row hand strips.
</objective>

// src/core/model.ts — DraftState gains two arrays, in the shape `picks` already uses
export interface CardPlay {
  playerId: string;
  value: number;
  round: number;
  /** The seq of the action that recorded it — what the tiebreak and a retraction target. */
  seq: number;
}

export interface ResolvedOrder {
  round: number;
  order: string[];
}

// src/core/actions.ts
export const CARDS_PLAYED = 'cards/played';
export const ORDER_RESOLVED = 'order/resolved';

export interface CardsPlayedPayload {
  type: typeof CARDS_PLAYED;
  playerId: string;
  /** 1..config.rounds. */
  value: number;
  /** 1-based, stamped at the edge from `selectCurrentRound`. */
  round: number;
}

export interface OrderResolvedPayload {
  type: typeof ORDER_RESOLVED;
  round: number;
  order: string[];
}

// src/core/cards.ts
export function resolvePickOrder(plays: readonly CardPlay[]): string[];

// src/core/selectors.ts
export function selectCurrentRound(state: DraftState): number;
export function selectHand(state: DraftState, playerId: string): number[];
export function selectCardPlayOrder(state: DraftState, round: number): string[];
export function selectResolvedOrder(state: DraftState, round: number): string[] | null;
export function selectCardsPlayedThisRound(state: DraftState, round: number): CardPlay[];
