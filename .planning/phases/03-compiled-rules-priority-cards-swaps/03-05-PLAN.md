## Phase Goal

Verbatim from `.planning/ROADMAP.md` §Phase 3 — this Goal line is not in `As a … I want to … so
that …` form and was not rewritten here; run `/gsd mvp-phase 3` if the three-slot form is wanted.

> The draft becomes the one the spec describes — composition requirements compile into a round
> schedule that types the team slots, players bid priority cards for turn order over that visible
> schedule, and swaps can only take something the target slot allows.

**Slice delivered by this plan:** a host who bans 50 species' worth of Mega formes and then asks for
3 Megas at 8 players sees `Start draft` disabled with the arithmetic and a next action that names
the right list — and a host who passes the gate gets a pool that provably cannot starve a Mega
round.

<objective>
Make the Mega-round arithmetic a blocking gate, and make the draw honour it.

Purpose: this is the phase's fail-closed boundary. A Mega round with an empty offer is the
mid-draft death RULE-07 exists to prevent, and there is no runtime validator left to catch it —
the compiler removed it by design. The gate **is** the guarantee.

Output: `notEnoughMegas` re-measured over eligible species, three new feasibility codes, a draw
whose Mega quota comes from eligible species rather than Mega-capable ones, and the config screen
wired to both.
</objective>
