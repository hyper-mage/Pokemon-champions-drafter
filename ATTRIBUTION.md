## Sprites

### What is committed here

`public/sprites/` contains 311 PNG files, one per draftable roster entry and per
Mega forme across both supported regulations, plus one generated placeholder.
All 311 are 96×96 pixels; the total is about 393 KB. They were downloaded from:

```
https://raw.githubusercontent.com/PokeAPI/sprites/master/sprites/pokemon/{id}.png
```

Files are named by PokeAPI's own numeric id (`460.png`, `10060.png`). They are
unmodified bytes — this project does not recolour, rescale, or re-encode them.

`public/sprites/_placeholder.png` is **not** from PokeAPI. It is generated by
`scripts/build-sprites.mjs` at the measured native size and is original to this
project.

### The licence, read in full

**Source:** `https://raw.githubusercontent.com/PokeAPI/sprites/master/LICENCE.txt`
**Read on:** 2026-08-04

Note the British spelling. The American `LICENSE.txt` at that path returns HTTP
404; `LICENCE.txt` is the real file. It is 6,654 bytes and opens, verbatim:

> All image contents within are Copyright The Pokémon Company.
>
> This repository is distributed under CC0 1.0 Universal

The remainder of the file is the standard CC0 1.0 Universal legal code, beginning
at its "Statement of Purpose" heading.

### What that permits — and what it does not

**Redistribution of these sprite files is permitted.** PokeAPI places its
repository under CC0 1.0 Universal, which waives PokeAPI's own rights in the
compilation and imposes no conditions on downstream use, including no attribution
requirement.

**The CC0 grant does not extend to the artwork.** This is the whole point of the
file's first line, and it is stated before the CC0 declaration rather than after
it. PokeAPI is explicit that the image contents are Copyright The Pokémon Company.
CC0 can only waive rights the person applying it actually holds; PokeAPI does not
hold copyright in Pokémon artwork and cannot place it in the public domain. So:

- ✅ PokeAPI raises no obstacle to this project shipping the files.
- ❌ The sprites are **not** public domain, and nothing in this repository should
  be read as saying they are.
- ❌ Downstream reuse for commercial purposes is not cleared by CC0 here. Anyone
  copying these files inherits the same underlying rights position, not a clean one.

This is precisely why this project's posture is non-commercial with no ads and a
visible disclaimer. The permission that matters is not CC0 — it is the ordinary
tolerance extended to non-commercial fan works, which is a posture, not a licence.

This section resolves an item the project's own research had flagged as
unresolved and LOW confidence. It is now read, quoted, and dated.

## Roster and legality data

Which Pokémon are legal in a given Champions regulation, their types, base stats,
abilities, Mega formes and Mega stones all come from
**[smogon/pokemon-showdown](https://github.com/smogon/pokemon-showdown)**, npm
package `pokemon-showdown` pinned at exactly `0.11.11`, read through
`Dex.mod('champions')` and `Dex.mod('championsregma')`.

The package is a **devDependency**. It is used by `scripts/build-roster.mjs` at
build time to produce the committed snapshots in `public/data/`, and ships zero
bytes to the browser.
